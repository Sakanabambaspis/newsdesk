# CONTEXT — domain glossary

Glossary only. No implementation details, no decisions, no spec content.

## Episode

The audio rendering of one daily digest. There is exactly one episode per
digest: "episode" and "the morning briefing" are the same thing. An episode
has no selection rules of its own — it consumes whatever the global daily
digest contains. If per-watchlist briefings ever exist, they will be a new
term, not a property of Episode.
